SoC Architecture
El SoC AINeuronX N200 está compuesto por una malla de tiles homogéneos interconectados mediante un Network-on-Chip (NoC) bidimensional.

Bloques principales:

Tiles de cómputo

NoC mesh

Control y clock/reset global

Cada tile opera de forma autónoma y se comunica exclusivamente a través del NoC, eliminando dependencias globales rígidas.
