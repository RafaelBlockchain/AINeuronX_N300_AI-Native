NoC Architecture
El NoC utiliza una topología 2D mesh con routers idénticos en cada nodo.

Características:

5 puertos por router (N, S, E, W, Local)

Flow control ready/valid

Virtual Channels parametrizables

Escalabilidad desde 2×2 hasta 64×64 sin cambios RTL

El ruteo inicial es simple y determinista, priorizando verificabilidad.
